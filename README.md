Trabalho prático desenvolvido no âmbito da unidade curricular de **Tecnologias Web (TWeb)** da Licenciatura em Engenharia Informática no **Instituto Superior de Engenharia de Coimbra (ISEC)**.

O projeto consiste no desenvolvimento de uma réplica fiel, moderna e responsiva do portal da companhia aérea **Air France**, aplicando as melhores práticas de marcação semântica em HTML5, estilização avançada em CSS3 e interatividade dinâmica com JavaScript puro (*Vanilla JS*).

---

## ✈️ Funcionalidades Implementadas

- **Navegação & Cabeçalho Responsivo:**
  - Barra de navegação com logotipo oficial, opções de voo, menu de idiomas e acesso à área de cliente.
  - Menu retrátil adaptável para ecrãs móveis e tablets.

- **Módulo de Pesquisa e Reserva de Voos:**
  - Seleção de tipo de viagem (Ida e Volta / Apenas Ida).
  - Seleção de aeroportos de partida e destino, datas e classe de viagem.

- **Carrossel de Destaques & Notícias:**
  - Apresentação dinâmica de destinos turísticos em destaque e promoções de viagens.
  - Transições fluidas e controlos de navegação.

- **Modal de Autenticação de Utilizador:**
  - Janela modal interativa para início de sessão / registo com validação visual de campos de formulário.

- **Rodapé Corporativo:**
  - Ligações úteis, badges de aplicações móveis (App Store / Google Play) e informações de suporte.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Layouts flexíveis e responsivos com **Flexbox** e **CSS Grid**, variáveis CSS e animações de transição.
- **JavaScript (ES6):** Manipulação dinâmica da árvore do DOM, controlo de modais, listeners de eventos e validações de formulário sem bibliotecas externas.

## 🚀 Como Visualizar

Não é necessário qualquer servidor web complexo:

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/Pedro2024136184/airfrance-clone-tweb.git
   cd airfrance-clone-tweb
   ```

2. **Abrir a página:**
   - Dê um duplo clique no ficheiro `airfrance.html` ou abra-o diretamente em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
   - Em alternativa, utilize a extensão *Live Server* do Visual Studio Code.
